# P2P Exchange Bot

Телеграм-бот для P2P обмена валют. Позволяет пользователям создавать заявки на обмен валют и находить контрагентов для сделок.

## Функциональность

- 💱 Актуальные курсы валют (обновление каждые 5 минут)
- 📝 Создание заявок на обмен
- 🔍 Поиск открытых заявок
- 📋 Управление своими заявками
- 🤝 Система подтверждения выполнения сделок
- 📨 Уведомления о статусе заявок

### Поддерживаемые валюты

- 🇷🇺 RUB (Российский рубль)
- 🇰🇿 KZT (Казахстанский тенге)
- 🇺🇸 USD (Доллар США)
- 🇪🇺 EUR (Евро)

### Способы оплаты

- Kaspi Bank 🟡
- Halyk Bank 💛
- Jusan Bank 🔵
- QIWI 🥝
- Сбербанк 💚
- Тинькофф 💎

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/p2p_bot.git
cd p2p_bot
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или
venv\Scripts\activate  # Для Windows
pip install -r requirements.txt
```

3. Создайте файл `.env` и добавьте необходимые переменные окружения:
```env
BOT_TOKEN=your_telegram_bot_token
ADMIN_IDS=[12345,67890]  # ID администраторов
EXCHANGE_RATE_API_KEY=your_api_key  # Опционально
```

4. Запустите бота:
```bash
python main.py
```
